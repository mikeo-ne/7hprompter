Sampler how-to

        
    
          
  1. Drop audio or Load demo break (synthetic 92 BPM dust break). Audio never leaves your browser — AudioContext.decodeAudioData only.
    2. 
          
  2. Auto-chop finds transients via short-term energy + adaptive threshold. Trim Sensitivity / Min-slice, or hit 16 equal. Drag markers to tweak.
    3. 
          
  3. Pads 4×4 = 16 per bank, A/B = 32 slices. LEDs mirror Serato. Click / QWERTY (Q W E R / A S D F / Z X C V / 1 2 3 4) / MIDI notes 36–67.
    4. 
          
  4. Slice plays each chop at original pitch. Chromatic pitches the selected chop across all 16 pads (C2 root + semitone). Gate vs One-shot.
    5. 
          
  5. Export WAV or ZIP. All slices are cut via OfflineAudioContext-grade slicing and encoded to 16-bit WAV with proper RIFF headers — ready for MPC / Serato / DAW.
    6. 
        

      

    


    

      

    


    

      

        

          
7H Music Prompter

          
Elite instrumental prompt engineer for Suno v4, Udio, Stable Audio, and ElevenLabs. Input a beat idea or twist the kits. Output is always dual-format, always instrumental.

        

        

          
Tag weighting (order is load-bearing)

          
Genre → Subgenre/Mood → Primary Instruments → Percussion Style → Production/Mix → BPM & Key → instrumental, no vocals

          
Style strings stay under 200 characters. Longer copy gets dropped. Conversational sentences are worse than comma tags.

        

        

          
Dual output

          
    
            
  • Output A — Style / Tag Box — condensed comma-separated tags.
    • 
            
  • Output B — Structure & Metatags — [Instrumental], [Intro], [Verse], [Drop], [Outro].
    • 
            
  • Negative Tags — copy to Exclude. Vocals never belong in a beat prompt.
    •
