7H Music Prompter

          
Elite instrumental prompt engineer for Suno v4, Udio, Stable Audio, and ElevenLabs. Input a beat idea or twist the kits. Output is always dual-format, always instrumental.

        

        

          
Tag weighting (order is load-bearing)

          
Genre → Subgenre/Mood → Primary Instruments → Percussion Style → Production/Mix → BPM & Key → instrumental, no vocals

          
Style strings stay under 200 characters. Longer copy gets dropped. Conversational sentences are worse than comma tags.

        

        

          
Dual output

          
    
            
  • Output A — Style / Tag Box — condensed comma-separated tags.
    • 
            
  • Output B — Structure & Metatags — [Instrumental], [Intro], [Verse], [Drop], [Outro].
    • 
            
  • Negative Tags — copy to Exclude. Vocals never belong in a beat prompt.
    •

Chop Sampler — Serato-style, in-browser

          
Drop audio, auto-chop transients (energy + threshold + min-distance), 16 pads × 2 banks = 32 slices, QWERTY (Q W E R A S D F Z X C V 1 2 3 4) and MIDI (C1–D#2), slice vs chromatic, WAV + ZIP export. All local via Web Audio.

        

        

          
Stem Splitter — Serato Sample-like (DSP Lite)

          
One-click Split Stems into Vocals / Drums / Bass / Melody using in-browser DSP (no upload, no AI server). Bass = lowpass 250Hz, Vocals = centre mid 300–3400Hz, Drums = side + transient highpass, Melody = remainder instrumental. Solo/mute per stem, audition, then Chop This Stem to send any stem to the 32 pads. Export stems as WAV/ZIP. For studio-grade AI (Demucs), export the original and run externally — this stays instant and private.
