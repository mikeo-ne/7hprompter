7H Music Prompter

          
Elite instrumental prompt engineer for Suno v4, Udio, Stable Audio, and ElevenLabs. Input a beat idea or twist the kits. Output is always dual-format, always instrumental.

        

        

          
Tag weighting (order is load-bearing)

          
Genre → Subgenre/Mood → Primary Instruments → Percussion Style → Production/Mix → BPM & Key → instrumental, no vocals

          
Style strings stay under 200 characters. Longer copy gets dropped. Conversational sentences are worse than comma tags.

        

        

          
Dual output

          
    
            
  • Output A — Style / Tag Box — condensed comma-separated tags.
    • 
            
  • Output B — Structure & Metatags — [Instrumental], [Intro], [Verse], [Drop], [Outro].
    • 
            
  • Negative Tags — copy to Exclude. Vocals never belong in a beat prompt.
    •
